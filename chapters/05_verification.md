## Chapter 5: Verifying Installation

### 1. What is Verification?
After installing, you must verify that the `vss` executable is available in your shell session.

### 2. Checking VSS Version
Open a new PowerShell or Command Prompt window and type:
```bash
vss --version
```

Expected Output:
```
VSS Programming Language v3.0.0 (x64-windows)
Compiled with Native HTTP, SQLite, Crypto, and Ecosystem Tools.
```

### 3. Checking VSS CLI Help Menu
To see all supported CLI options:
```bash
vss help
```
